Ludum Dare 60 - "Old Tech"
============================

Ludum Dare 60 Entry by Jimbly - "Game Title"

* Play here: [dashingstrike.com/LudumDare/LD60/](http://www.dashingstrike.com/LudumDare/LD60/)
* Using [Javascript libGlov/GLOV.js framework](https://github.com/Jimbly/glovjs)
* Forked from [#jam-template](https://github.com/Jimbly/glovjs/tree/jam-template) branch including:
  * Title and menu screens to access engine's high score display, keybinds, etc

Acknowledgements:
* [IBM VGA 8x16 font](https://int10h.org/oldschool-pc-fonts/fontlist/?1#ibm-g2)

Start with: `npm start` (after running `npm i` once)
